# Проектная работа «Посмотри в окно»

## Описание проекта

«Посмотри в окно» — это интерактивное веб-приложение, которое позволяет пользователям находить и смотреть короткие видеоролики из разных городов в зависимости от выбранного времени суток (утро, день, ночь).

В отличие от предыдущих учебных проектов, где верстка создавалась с нуля, в этой работе HTML-разметка и JavaScript-логика были предоставлены в стартовой заготовке. Здесь нужно было добавить элементам css свойства, а также новые свойства, которых не было в предыдущем проекте, такие как: hover, active, focus. Было довольно интересно познакомиться с псевдоэлементами и псевдоклассами.

## Инструкция по запуску

Проект представляет собой статический веб-сайт.

**Системные требования:**
Любой современный браузер (Chrome, Firefox, Safari, Edge) актуальной версии с поддержкой селектора `:has()`.

**Как запустить проект:**

1. Склонируйте репозиторий на свой компьютер: git clone (проект) , SSH либо же через zip файл или  

2. Откройте папку с проектом в вашем редакторе кода (например, VS Code).

3. Просто откройте файл `index.html` в браузере. Для автоматического обновления страницы при редактировании кода рекомендуется использовать расширение **Live Server** для VS Code
